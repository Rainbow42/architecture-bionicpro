# Проверки

Здесь сохраняется фактический вывод команд. Учебный стенд запущен через Podman Compose на ARM64; исходный `docker-compose.yaml` не требует Docker-specific API.

`check_reports.py` проверяет живые ClickHouse и MinIO после настоящего Airflow DAG, но задаёт идентификатор пользователя в тестовом процессе. Это не сквозная проверка входа. Настройка OTP, вход через Яндекс ID и скачивание из браузера после полного входа пока не подтверждены.

Пароли, токены, OTP-секреты и QR настройки второго фактора сюда не входят.

Подтверждены: 15 модульных тестов, сборка React, аудит зависимостей фронтенда и API, импорт realm и LDAP-роли, обязательность OTP в конфигурации, успешные DAG `reports_batch` и `reports_cdc`, CDC INSERT/UPDATE/DELETE, отчёты из настоящих ClickHouse и MinIO, кеш-попадание без запроса OLAP, ответ 401 анонимному запросу CDN и `nginx -t`.

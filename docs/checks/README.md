# Проверки

Здесь сохраняется фактический вывод команд. Учебный стенд запущен через Podman Compose на ARM64; исходный `docker-compose.yaml` не требует Docker-specific API.

`check_reports.py` проверяет живые ClickHouse и MinIO после настоящего Airflow DAG, но задаёт идентификатор пользователя в тестовом процессе. Это не сквозная проверка входа. Отдельно проверен вход из браузера через настоящую сессию Keycloak после пользовательской настройки OTP и скачивание отчёта. Проверка настоящего входа через Яндекс ID описана в [yandex.md](yandex.md).

Пароли, токены, OTP-секреты и QR настройки второго фактора сюда не входят.

Подтверждены: сборка React, аудит зависимостей фронтенда и API, импорт realm и LDAP-роли, обязательность OTP в конфигурации, успешные DAG `reports_batch` и `reports_cdc`, CDC INSERT/UPDATE/DELETE, отчёты из настоящих ClickHouse и MinIO, кеш-попадание без запроса OLAP, ответ 401 анонимному запросу CDN и `nginx -t`.

`unit.txt` и `oidc.txt` — сохранённые результаты автоматических тестов до их удаления из проекта. В коммите `2fe31a7` прошли все 24 теста; исходники остались в истории Git. Эти логи не означают, что тесты можно запустить из текущей версии проекта.

После пользовательской настройки OTP проверены вход через сессию Keycloak, скачивание JSON с отчётом и перезагрузка страницы спустя более 120 секунд без повторного входа. Состояние приложения после обновления токена — [browser-login.png](browser-login.png).

С настоящей сессией `prothetic1` проверены CDN MISS → HIT для одного URL, совпадение содержимого и `Cache-Control: private, no-store`. Существующий отчёт `prothetic2` вернул 403. После выхода прежний URL собственного отчёта и API отчётов вернули 401. Вывод браузерной проверки — [cdn-browser.txt](cdn-browser.txt), снимок результата — [cdn-browser.jpg](cdn-browser.jpg). Временная страница вызывала обычные API приложения с сессионной cookie, без подмены аутентификации, и после проверки удалена из контейнера.
